# Project instructions — dbsql

dbsql is SQLite 3.53.4's SQL language running on Berkeley DB (libdb
v2026.10.2) storage, written in Berkeley DB style.

## Read first

- `.agent/NORTH_STAR.md`: the goal and its non-negotiable invariants.
- `.agent/STEERING.md`: the live tracker (decisions, phase status, build
  host). Update it when a phase lands.
- `.agent/steering/`: the detailed design.
  - `TRANSFORM.md`: SQLite → dbsql naming and the transform pipeline.
  - `STORAGE.md`: the libdb storage manager.
  - `TESTING.md`: test tiers and release gates.
  - `DIVERGENCES.md`: justified differences from SQLite.

`.agent/archive/` holds old reports. It is gitignored and is not guidance.
`.agent-steering-domains.md` is tool-generated (local, gitignored) and holds
the general C conventions.

## Rules

- SQLite-derived code in `src/` is generated by `dist/transpile`. Fix the
  transformer or the patch queue, not the output.
- Use libdb's public API only (`db.h`), never libdb internals.
- Nothing is "done" without a passing test on the FreeBSD build host. Never
  claim a result you did not run.
- Commits are signed and authored by `Greg Burd <greg@burd.me>`, with
  Conventional Commit messages. Work on a branch. Push only when asked.

See .agent-steering-domains.md for domain-specific steering (local).
